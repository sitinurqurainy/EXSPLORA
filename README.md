# EKSPLORA

**Platform Ekstrakurikuler Sekolah** — proyek website untuk mata kuliah Sistem Informasi.

## Fitur pada versi awal
- Halaman beranda responsif.
- Daftar contoh kegiatan ekstrakurikuler.
- Pencarian kegiatan.
- Navigasi yang menyesuaikan layar ponsel.
- Pengenalan empat peran pengguna: siswa, ketua ekstrakurikuler, guru pembina, dan admin sekolah.

## Struktur file
- `index.html` — struktur halaman.
- `style.css` — desain dan tata letak.
- `script.js` — interaksi menu dan pencarian.
- `README.md` — dokumentasi proyek.

## Menjalankan secara lokal
Buka `index.html` di browser. Untuk pengembangan yang lebih nyaman, gunakan ekstensi Live Server di Visual Studio Code.

## Publikasi dengan GitHub Pages
1. Unggah semua file ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pada bagian build/deployment, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu simpan.
5. Tunggu proses publikasi dan buka URL yang diberikan GitHub.

## Catatan
Ini adalah prototipe antarmuka awal. Fitur login, penyimpanan data permanen, pendaftaran yang tercatat, absensi, dan laporan dinamis belum diaktifkan. Fitur tersebut membutuhkan backend/database dan kontrol akses yang aman.
